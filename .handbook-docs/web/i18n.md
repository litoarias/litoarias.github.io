# Internationalization

- **WEB-I18N-001 (MUST)** Each language has its own URL (`/<lang>/…`); English
  (or the source language) lives at the root. The project wiki lists the
  shipped languages.
- **WEB-I18N-002 (MUST)** Copy lives in one file per language, deep-merged
  over the source language. The build reports missing keys; no page ships
  with untranslated keys.
- **WEB-I18N-003 (MUST)** Do not rename or move existing language folders or
  page paths that external systems link to (App Store Connect, ads,
  campaigns). Add redirects when a path must change.
- **WEB-I18N-004 (SHOULD)** Strings shared with the app come from the app's
  String Catalog export so both say the same thing.
- **WEB-I18N-005 (MUST)** Every page sets `<html lang>`, and right-to-left
  languages set `dir="rtl"` and are visually checked.
- **WEB-I18N-006 (SHOULD)** Automatic language redirection happens only on the
  first visit, respects a stored user choice, and never traps crawlers.
