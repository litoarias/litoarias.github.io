# Performance

- **WEB-PERF-001 (MUST)** Images are served in modern formats (WebP/AVIF with
  fallback), sized for their slot, with `width`/`height` set and
  `loading="lazy"` below the fold.
- **WEB-PERF-002 (SHOULD)** At most two font families; preload the critical
  font and use `font-display: swap`.
- **WEB-PERF-003 (MUST)** No third-party script without a clear purpose; each
  one is listed in the privacy policy.
- **WEB-PERF-004 (SHOULD)** Lighthouse mobile score of 90+ for performance and
  accessibility on the home page.
