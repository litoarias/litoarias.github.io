# SEO And Sharing

- **WEB-SEO-001 (MUST)** Every page has a unique `<title>` and
  `<meta name="description">` in its language.
- **WEB-SEO-002 (MUST)** Language variants declare `hreflang` alternates
  (including `x-default`) and a self-referencing canonical URL.
- **WEB-SEO-003 (MUST)** `sitemap.xml` lists every public page in every
  language and is updated in the same change that adds or removes pages;
  `robots.txt` points to it.
- **WEB-SEO-004 (SHOULD)** Open Graph and Twitter card tags with a 1200×630
  image per language when the image contains text.
- **WEB-SEO-005 (SHOULD)** App landings include `MobileApplication`
  structured data and the Apple Smart App Banner meta tag.
