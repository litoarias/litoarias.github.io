# Accessibility

- **WEB-A11Y-001 (MUST)** Semantic structure: one `h1`, ordered headings,
  landmarks (`header`, `main`, `footer`, `nav`).
- **WEB-A11Y-002 (MUST)** Every meaningful image has `alt` text in the page
  language; decorative images use `alt=""`.
- **WEB-A11Y-003 (MUST)** Text contrast meets WCAG AA; interactive elements are
  keyboard-reachable with a visible focus style.
- **WEB-A11Y-004 (MUST)** Animations respect `prefers-reduced-motion`.
- **WEB-A11Y-005 (SHOULD)** Support `prefers-color-scheme` when the app has a
  dark mode.
