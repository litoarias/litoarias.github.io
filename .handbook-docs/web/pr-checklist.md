# Web PR Checklist

- [ ] Sources edited, site rebuilt, and generated pages committed together
      (WEB-SITE-001).
- [ ] Every shipped language updated; no missing keys (WEB-I18N-002).
- [ ] No path linked from App Store Connect or campaigns renamed
      (WEB-I18N-003, WEB-APP-004).
- [ ] Titles, descriptions, `hreflang`, canonical, and sitemap updated
      (WEB-SEO-001/002/003).
- [ ] No personal data on any page (WEB-APP-002).
- [ ] Privacy policy still matches the app (WEB-APP-003).
- [ ] Checked on mobile width, in dark mode, and with reduced motion
      (WEB-A11Y-004/005).
- [ ] No agent or docs file is published on the site (WEB-SITE-008).
